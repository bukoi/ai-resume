# Project Instructions

## Architecture

- Backend: FastAPI, Python, SQLAlchemy, Alembic, PostgreSQL.
- Frontend: React, TypeScript, Tailwind CSS.
- Follow the existing project structure and coding conventions.

## Development Rules

- Inspect existing code before modifying it.
- Prefer small, focused changes over unnecessary rewrites.
- Do not modify environment files or expose secrets.
- Use Pydantic schemas for API validation.
- Use SQLAlchemy models and Alembic migrations for database changes.
- Add or update tests for new functionality.
- Run relevant tests and report any failures.
- Explain important changes and tradeoffs.
- Ask before destructive operations or major architectural changes.
- Group related functionality together. Create modules where all methods work toward the same purpose.
- split the code into small, focused files rather than putting everything in one place
